# Corporate-Finance-Analytics-Portfolio
US Sales Finance Analytics &amp; Valuation Portfolio
<img width="1473" height="827" alt="image" src="https://github.com/user-attachments/assets/36d0cd65-d0ab-49cd-9f44-f28b8b7c3302" />
This project simulates a POS transaction between a third party retail channel and apple, tracking $192M in allocated funding and promotional allowances across unique retail transactions. In this analysis I looked at the performance metrics across four major retail distributors (BestBuy, Verizon, AT&T, and Target) throughout four core domestic sales regions
